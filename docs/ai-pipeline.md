# AI pipeline

Text triage is a deterministic keyword baseline that suggests a category and linked department. Priority uses transparent safety keywords, category, and affected-person count, returning a rationale and configurable demo SLA. Duplicate suggestions combine token overlap, same category, and approximate coordinate proximity. Nothing automatically rejects a report or makes a verified emergency finding.

This repository includes no trained model, model weights, measured accuracy, machine translation, or vision classifier. Image uploads are type/size checked and fingerprinted; the returned analysis explains that visual weights are absent. Browser speech recognition is not implemented in this version. The FAQ assistant returns only a small local curated answer set and a source note; unmatched queries return a clear not-known response.
